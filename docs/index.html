プライバシーポリシー — YT Transcript to Clipboard

更新日：2026年10月21日

この拡張機能は、利用者がYouTube動画ページ上でツールバーのアイコンを押したときにのみ処理します。現在の動画のタイトル、チャンネル名、URL、取得できる場合は公開日、字幕、タイムスタンプON時の字幕時刻を読み取り、文章を整形して利用者の端末のクリップボードへコピーします。

字幕はYouTubeに直接問い合わせるか、必要に応じてYouTubeの文字起こし画面を自動で開いて取得します。開発者運営サーバーは使用せず、開発者による字幕・閲覧履歴の収集や保存、利用状況解析、広告、情報販売・第三者提供はしません。動画情報と字幕は端末内で処理します。字幕取得の通信はYouTubeに対して行われます。コピーした内容の保持は端末側のクリップボードの仕様によります。

保存するのは、タイムスタンプON/OFFの真偽値だけです（初期設定OFF）。右クリックメニューで設定を変更できます。拡張機能を削除すると拡張機能内の保存設定も削除されます。関係のないタブの情報をバックグラウンドで読み取りません。

使用権限：activeTab（クリックした動画タブ）、scripting（字幕取得とコピー）、clipboardWrite（コピー）、contextMenus（右クリック設定）、storage（設定保存）。

本拡張機能によるユーザーデータの使用は、Chrome ウェブストアのユーザーデータポリシー（Limited Use 要件を含む）に従います。

本拡張機能はYouTubeと提携していない非公式のツールです。公開者：Yosio-DMZ-C。お問い合わせ：GitHub Issues。

Privacy Policy — YT Transcript to Clipboard

Last updated: 2026-10-21

This extension operates only when the user clicks its toolbar icon on a YouTube video page. It reads the current video's title, channel name, URL, available publication date and subtitles, including timing data when selected. It formats this content and places it on the device clipboard.

The extension accesses available YouTube captions directly from YouTube or, when needed, opens the site's transcript panel automatically. We do not run a separate server, collect or retain transcripts, use analytics, display ads, or sell or transfer user data to us or third parties. The current video's information and captions are processed locally. YouTube may receive the caption requests needed to retrieve subtitles. The user's clipboard is managed by their device.

The sole saved setting is a local true/false preference for optional timestamps, initially off. Users can turn it off using the right-click menu or uninstall the extension to remove its locally stored extension data. The extension does not read unrelated tabs in the background.

Requested permissions: activeTab (the clicked video tab), scripting (caption extraction and clipboard copy), clipboardWrite (clipboard copy), contextMenus (timestamp toggle), storage (local timestamp setting).

Our use of user data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

This independent tool is not affiliated with YouTube. Publisher: Yosio-DMZ-C. Contact: GitHub Issues.
